## What Nibfin is

**Nibfin Core** runs the Scope, Shape, Deliver and Accept roles against a GitHub
repository. Every decision it makes reads Issues, labels, branches, pull requests
and checks from GitHub, and every result is written back there. Nothing is kept
anywhere else.

**gh nibfin** is the operator's side: a GitHub CLI extension and a local Dashboard.
It installs the Runners where the agents work, logs their provider CLI in, prepares
a repository with `init`, and shows where each Issue stands.

## From Issue to merge

An Issue with the `scope` label and one Assignee runs on that Assignee's Runners.
Each stage hands over through GitHub, and a person can stop it at any point.
